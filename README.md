# WEAPON ATLAS · 武器数据工坊

一个无需安装前端依赖的通用武器数据库与 TTK 分析网页。内置的五把武器均为**虚构演示数据，不代表任何游戏的真实平衡数据**。

## 启动

Windows 下双击本目录的 `启动.cmd`，或上一级目录的 `启动武器数据工坊.cmd`。需要 Node.js 20 或更新版本。启动器会打开浏览器，运行期间保留服务窗口，关闭时按 Ctrl+C。

也可以在本目录执行：

```text
npm start
```

然后访问 <http://127.0.0.1:4173>。无需执行 `npm install`。如端口被占用，可先设置 `PORT` 环境变量再启动；服务不会自动换端口。服务器仅绑定本机地址。

## 使用

- **武器分析**：选择武器及射击模式，设置 100、150 或 300 血量、距离和是否计入子弹飞行时间。人体分区展示当前距离下的部位伤害，可选择部位计算固定命中 BTK / TTK，也可设置各部位命中概率计算混合结果。
- **多武器比较**：在左侧武器列表勾选对比框，使用同一血量、距离、命中方案和弹速设置查看曲线及横向对比表。当前查看的武器会自动参与对比，每把武器可以独立选择射击模式。
- **临时试算**：手动填写一把武器的数据进行计算，临时数据不会自动写入数据库。
- **数据维护**：新增、复制、修改或删除武器；编辑分段基础伤害、全程部位倍率和射击模式；导出 JSON 数据库，也可导入 JSON 后继续维护。

浏览器会保存本地草稿。草稿属于当前浏览器、当前网页地址，不会自动在设备间同步；清除网页存储可能删除它。重要数据请导出 JSON 备份。维护页采用显式保存，未保存的编辑也会保留为本地草稿。

JSON 导出仅包含已经保存的数据库，不包含未保存的编辑草稿或临时试算武器。临时试算结果在当前页面会话中使用；尚未提交计算的临时编辑仍可通过本地草稿恢复。

导入 JSON 后先查看预览，再选择“合并更新”或“替换整个武器库”。默认合并更新，同 ID 的武器会被覆盖；替换会移除文件中未包含的现有武器。校验失败时不改变当前武器库。导入前会保存一份本地备份，可在维护页恢复；重要数据仍建议先导出独立文件。

可导入的完整示例文件为本目录下的 [`dist/example-database.json`](dist/example-database.json)，内容与内置示例库一致。运行网页后，也可以访问 <http://127.0.0.1:4173/example-database.json> 查看或另存。导入上限为 5 MB；确认导入或恢复备份会清除当前未保存的编辑草稿，确认前请先保存所需修改。仅保留最近一次导入前的数据库备份。

## 伤害模型

每个射程段具有自己的基础伤害。最后一段的 `until` 为 `null`，表示延伸至更远距离；距离恰好等于分界点时，使用下一段伤害。

每个部位只有一个全程倍率，不支持个别射程覆盖。部位实际伤害为“当前射程基础伤害 × 该部位全程倍率”。在维护页输入某个参考射程的实际伤害，可以反推全程倍率，并同步改变所有射程下该部位的伤害。已确定倍率后，修改基础伤害保持倍率不变。

人体分为头、颈、胸、腹、上臂、前臂、大腿和小腿。左右对称区域共用同一类部位数据。

## 计时口径

TTK 从首次扣动扳机起算，扳机延迟只计入一次。对于固定射击间隔，发射到第 N 发的时间为“扳机延迟 + (N−1) × 枪间隔”。

- 自动与半自动使用 `60000 ÷ RPM` 毫秒的枪间隔；半自动按允许的最快节奏计算。
- 栓动／泵动使用完整拉栓周期，即“本枪开火到下一枪可以开火”的间隔，不再叠加 RPM 间隔。
- 点射记录每组发数、组内射速和组间间隔。组间间隔是“上一组最后一发射出，到下一组第一发射出”的完整时间。
- 开启弹速影响时，加上“距离 ÷ 弹速”的飞行时间，假定弹速恒定。

固定部位的 BTK 为达到目标血量所需的整数发数。混合命中默认每一发独立按部位概率命中、所有子弹均命中，结果为精确期望击杀发数与期望 TTK，并展示击杀发数概率分布；期望 BTK 可以是小数。混合计算先求击杀发数分布，再按真实发射时间轴加权，不能用平均伤害直接推算，也不能把期望 BTK 直接代入点射时间公式。

显示值可能四舍五入，计算使用内部数值；伤害按 12 位有效数字规范化后，以十进制整数比较击杀阈值，减少倍率反推造成的浮点噪声。计算器设有复杂度上限，异常或过于复杂的数据会显示错误。当前模型不包含空枪、护甲特殊减伤、弹速衰减、穿透、弹丸散布、换弹和玩家反应时间。

## 文件与测试

`dist/` 是可独立部署的静态网页；`server.mjs` 提供本地预览服务。数据库 schemaVersion 为 1，结构由计算核心校验。

执行计算测试：

npm test
